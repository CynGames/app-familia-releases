# Aplicación de Familia

Descarga la versión para Windows 10/11 de 64 bits desde
[Releases](https://github.com/CynGames/app-familia-releases/releases/latest).

En la versión más reciente, abre **Assets** y ejecuta el único archivo
`Aplicacion-de-Familia_<version>_x64-setup.exe`.

Una vez instalada, la aplicación busca actualizaciones firmadas y permite
instalarlas con **Actualizar y reiniciar**.

Los avisos de terceros, la oferta de código fuente y el inventario de
herramientas están incluidos dentro del instalador y también disponibles en la
raíz de este repositorio.
